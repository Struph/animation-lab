# animation-lab

Browser-Demo fuer ein WoW-inspiriertes Codex-Buch mit realistischer Blaetter-Animation.

## Wichtig fuer WoW

**Nein: StPageFlip kann nicht ingame in WoW verwendet werden.**

- StPageFlip = JavaScript fuer Browser
- WoW-Addons = nur Lua + XML + Texturen
- Diese Demo ist die visuelle Zielreferenz
- Fuer das Addon bauen wir spaeter eine eigene Lua/XML-Animation (aehnlicher Look, andere Technik)

## Start

1. `codex-demo.html` im Browser oeffnen
2. Cover wechseln (Allianz/Horde)
3. Seiten ziehen/klicken oder Lesezeichen nutzen
