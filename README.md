# animation-lab

Browser-Demo fuer ein WoW-inspiriertes Codex-Buch mit:

- Fraktions-Cover (Allianz/Horde)
- Oeffnungsanimation des Buchs
- Lesezeichen-Buttons zum direkten Sprung auf Seiten
- Blattereffekt beim Seitenwechsel

## Start

Einfach `index.html` im Browser oeffnen.

Optional mit lokalem Server:

```bash
python3 -m http.server 8000
```

Dann aufrufen:

`http://localhost:8000`
